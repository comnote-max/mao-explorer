## 日本語

### 一行紹介（40 字前後）
GitHub をふつうのフォルダのように使える、Git 不要のファイラー

### 短い説明（100 字前後）
エクスプローラーと同じ操作で GitHub をクラウドフォルダとして使えます。ファイルを開いて保存するだけで自動で送信。Git の知識はいりません。

### 詳しい説明
MAO Explorer は、GitHub を「みんなで使うクラウドフォルダ」として使うためのファイラーです。
見た目と操作は Windows のエクスプローラーとほぼ同じ。Git の言葉を覚えなくても、チームでファイルを共有し、履歴を残せます。

主な機能
- エクスプローラーと同じ操作（コピー・移動・名前の変更・プレビュー・タブ）
- ファイルを開いて保存すると、少し待つだけで自動でクラウドへ送信
- 「下書きフォルダ」で安心して編集し、終わったら本体に反映
- 同じところを別々に直してぶつかったときは、両方を並べて見比べて選べる
- いつでも以前の内容に巻戻し（後の履歴は消えません）
- 反映のお願い（プルリクエスト）の確認と反映
- Git 経験者向けの「クラシックモード」（commit / push / pull / branch / merge / log のグラフ）
- 20 言語に対応

こんな方に
- 見積書や資料をチームで共有したいが、Git は難しいと感じる方
- GitHub をバックアップ付きのクラウドフォルダとして使いたい方

ご注意
- GitHub アカウント（無料）が必要です。ログイン情報は Windows の資格情報マネージャーに安全に保存されます。
- コード署名がないため、初回起動時に「Windows によって PC が保護されました」と出る場合があります。「詳細情報」→「実行」で起動できます。

## English

### Tagline
A file explorer that lets you use GitHub like a normal folder — no Git required.

### Short description
Use GitHub as a shared cloud folder with a Windows Explorer–style UI. Open a file, save it, and MAO Explorer sends it to the cloud for you. No Git knowledge needed.

### Full description
MAO Explorer turns GitHub into a shared cloud folder for people who have never used Git.
It looks and works like Windows File Explorer, so your team can share files and keep a full history without learning Git commands.

Features
- Explorer-style UI: copy, move, rename, preview, tabs
- Auto-sync: save a file and it is sent to the cloud a few seconds later
- Drafts: edit safely in a draft folder, then apply it to the main version
- Side-by-side conflict resolution when two people change the same lines
- Roll back any file or the whole folder to an earlier point (later history is kept)
- Review and apply change requests (pull requests)
- Classic mode for Git users: commit / push / pull / branch / merge / log graph
- 20 languages

Notes
- A free GitHub account is required. Your sign-in is stored securely in Windows Credential Manager.
- The installer is not code-signed yet; Windows SmartScreen may warn on first run ("More info" → "Run anyway").
- Free and open source (MIT OR Apache-2.0). Made by maociva.

GitHub, file manager, cloud folder, file sharing, version history, backup, Git GUI, explorer
