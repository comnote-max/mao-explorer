# MAO Explorer デスクトップ版 仕様書 v1.1（たたき台）

> 2026-11-18 受領。ChatGPTと作成したたたき台。実現性評価は [FEASIBILITY.md](FEASIBILITY.md) を参照。

## 要旨
- 対象：Windows 11 / macOS、ブランド MAOCIVA、GitHub統合機能「MAO Git Explorer」
- 設計思想：「Gitと名前についているのに、普通のエクスプローラーとして使える」
- 用語置換：リポジトリ→プロジェクトフォルダ／メインブランチ→本体／ブランチ→仮想フォルダ／コミット→保存／クローン→初回同期／pull・push→同期／PR→本体へ反映依頼／マージ→本体に反映
- 技術案：Tauri 2 + Rust + React/TS、SQLite索引、libgit2(git2)、GitHub API、SMBはOS標準
- 画面：ツールバー＋アドレス＋検索／ツリー（PC・NAS・OneDrive・Google Drive・GitHub）／一覧／ステータスバー
- 同期状態：同期済み・未同期(灰)・ローカル変更あり(青)・送受信待ち・同期中・要対応(赤)・オフライン
- 権限別表示：反映権限なし→「本体へ反映依頼」、権限あり→「本体に反映」、閲覧のみ→反映操作なし。ブランチ保護は権限と別判定
- 責任者側：依頼ボタン点滅＋件数、内容確認→反映／修正依頼
- 安全：失敗時にローカル変更を破棄しない、NAS切断を削除扱いしない、取得ファイルを自動実行しない
- フェーズ：1 ファイラー → 2 索引検索 → 3 GitHub閲覧・同期 → 4 仮想フォルダ・権限別反映 → 5 配布
- 対象外：独自クラウド、独自NAS、自前チーム管理基盤
